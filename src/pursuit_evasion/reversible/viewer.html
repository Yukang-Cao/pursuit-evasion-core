How to read this view

The right axes are E forward/backward and left/right, measured in P's body frame. The slice fixes relative heading, P speed and E speed. Dragging either position changes the query marker. Rotating a vehicle or changing a speed changes the slice. Translating both cars together leaves this free-space value unchanged.

The heatmap is queried from stored signed fields and their first zero crossing. No new DP solve runs here. Gray means unresolved within this table's selected coverage, not proven escape. A negative speed reverses motion without rotating the body heading.

In recordings, P's actual mode, temporary waypoint, and E's declared strategy are shown above the world view. Editing detaches the recording: the interface then shows a hypothetical B1 decision, not a new simulated chase. The replay advances one recorded control step at a time so the slice and state remain synchronized; this is a diagnostic step-through, not real-time video.
